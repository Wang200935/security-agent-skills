# Acceptable Use Policy

This repository contains security testing skills for AI agents. The skills
themselves are dual-use — they describe methodologies used by both offensive
security professionals and defenders.

## Expectations

- Only test systems you own or have explicit written authorization to test.
- Follow responsible disclosure practices for any vulnerabilities found.
- Do not use these skills to cause harm, steal data, or disrupt services
  you are not authorized to access.
- Check and comply with all applicable local, national, and international
  laws regarding security testing, network access, and data collection.

## Scope

This policy applies to all content in this repository, including skills,
scripts, references, and documentation. It does not modify the MIT license
under which the code is distributed — it describes expected use.

## Reporting

If you find a vulnerability in this repository itself, or if you believe
content in this repository exposes sensitive data, see `SECURITY.md` for
reporting instructions.
